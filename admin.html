Java REST Endpoints & Authentication Cheatsheet

POST /api/auth/login

Validates fixed credentials (venkateswara / vitap2028 or admin / admin123).

Authenticates Google OAuth tokens or simulated account payloads.

POST /api/contact

Returns JSON list of all Java, Python, Android, Web, and ELK Stack projects.

GET /api/elk/logs

Streams structured JSON logs for Logstash ingestion & Kibana dashboards.

GET /metrics & /health

Prometheus metrics exposition & synthetic health probe endpoints.
